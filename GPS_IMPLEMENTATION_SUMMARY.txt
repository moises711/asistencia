🚀 INICIO RÁPIDO
===============================================================================

1️⃣  CONFIGURAR UBICACIÓN DE LA OFICINA:
    python manage.py configurar_gps \
      --latitud 10.5123456 \
      --longitud -75.3456789 \
      --radio 500 \
      --nombre "Oficina Principal"

2️⃣  VERIFICAR CONFIGURACIÓN:
    python manage.py shell
    >>> from asistencia.models import ConfiguracionGPS
    >>> ConfiguracionGPS.obtener_configuracion_activa()
    <ConfiguracionGPS: Oficina Principal (10.512346, -75.345679)>

3️⃣  ¡LISTO! Los usuarios pueden usar GPS en el dashboard

===============================================================================
🎯 CÓMO FUNCIONA PARA EL USUARIO
===============================================================================

PASO 1: Usuario abre Dashboard
        → Ve botón "📍 Ubicación GPS" con estado

PASO 2: Usuario hace click en "Ubicación GPS"
        → Navegador solicita permiso GPS
        → Usuario acepta
        → Se capturan coordenadas automáticamente

PASO 3: Sistema valida con servidor
        → Calcula distancia a la oficina (Haversine)
        → Compara con radio permitido
        → Muestra: ✓ "En la oficina (145m)" o ✗ "Fuera de rango"

PASO 4: Usuario marca entrada o salida
        → Se envían coordenadas GPS al servidor
        → Se guardan automáticamente en BD
        → Proceso completado

TIEMPO TOTAL: ~2-5 segundos

===============================================================================
📊 DATOS GUARDADOS EN BASE DE DATOS
===============================================================================

Para cada entrada/salida se almacenan:
  ✓ Latitud y longitud exactas
  ✓ Precisión GPS (margen de error en metros)
  ✓ Fecha y hora
  ✓ Usuario
  ✓ Estado de validación

TABLA: RegistroAsistencia
  - latitud_entrada: DecimalField
  - longitud_entrada: DecimalField
  - latitud_salida: DecimalField
  - longitud_salida: DecimalField
  - precisión_entrada: FloatField
  - precisión_salida: FloatField

TABLA: ConfiguracionGPS (Ubicación de la oficina)
  - nombre: CharField
  - latitud: DecimalField
  - longitud: DecimalField
  - radio_permitido_metros: IntegerField (default: 500)
  - activa: BooleanField

===============================================================================
🔌 API ENDPOINT
===============================================================================

POST /validar-gps/

REQUEST (JSON):
{
  "latitud": 10.5123456,
  "longitud": -75.3456789,
  "precisión": 5.5
}

RESPONSE (válido):
{
  "valido": true,
  "distancia": 145.32,
  "mensaje": "Distancia: 145.32m - Ubicación válida",
  "precision": 5.5,
  "radio_permitido": 500
}

RESPONSE (no válido):
{
  "valido": false,
  "distancia": 2500.50,
  "mensaje": "Distancia: 2500.50m - Fuera del rango permitido",
  "precision": 6.2,
  "radio_permitido": 500
}

===============================================================================
❓ SOLUCIÓN DE PROBLEMAS COMÚN
===============================================================================

❌ "Error - Configuración GPS no disponible"
✓ Solución: python manage.py configurar_gps --latitud X --longitud Y

❌ "No se pudo obtener la ubicación"
✓ Solución: Permitir GPS en navegador, habilitar GPS en dispositivo

❌ "Fuera del rango permitido"
✓ Solución: Estar en la oficina o ajustar radio_permitido_metros

❌ GPS no funciona en HTTP (desarrollo)
✓ Solución: Usar HTTPS en producción, localhost funciona con HTTP
