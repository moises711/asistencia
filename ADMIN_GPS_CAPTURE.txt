🚀 CÓMO USAR:

OPCIÓN 1: Desde el Admin (Panel)
─────────────────────────────────
1. Acceder a: http://localhost:8000/admin/asistencia/configuraciongps/
2. Hacer click en "Editar" (o crear una nueva)
3. Scroll al campo "Herramientas"
4. Click en botón "📍 Capturar Ubicación Actual"
5. Permitir GPS en el navegador
6. Los campos se llenan automáticamente
7. Click en "Guardar" (botón estándar de admin)

OPCIÓN 2: Página Dedicada de Captura
─────────────────────────────────────
1. Acceder a: http://localhost:8000/admin/capturar-gps/
2. Click en "📍 Capturar Mi Ubicación Actual"
3. Permitir GPS en el navegador
4. Ajustar parámetros si es necesario:
   - Radio permitido (20m por defecto)
   - Nombre de la oficina
5. Click en "💾 Guardar Ubicación"
6. ¡Listo! Ubicación guardada

🔗 ENDPOINTS:

GET /admin/capturar-gps/
└─ Página HTML para capturar GPS
   Requiere: Autenticado como admin/staff
   Retorna: HTML con interfaz de captura

POST /admin/guardar-gps/
└─ API para guardar las coordenadas
   Requiere: JSON + CSRF token
   Requiere: Admin/staff autenticado
   
   Body JSON:
   {
     "latitud": 10.5123456,
     "longitud": -75.3456789,
     "radio": 20,
     "nombre": "Oficina Principal"
   }
   
   Response:
   {
     "success": true,
     "message": "✅ Ubicación guardada exitosamente",
     "config": {
       "nombre": "Oficina Principal",
       "latitud": 10.5123456,
       "longitud": -75.3456789,
       "radio": 20
     }
   }
